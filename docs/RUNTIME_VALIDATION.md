# 曲边错位修复验证记录

本记录不是全量兼容性认证。以下修复期间曾暂停打包发布；v0.3.0 经用户批准进入发布，检查结果见文末。

## 2026-10-14 实机检查

环境：本机 WPS 12.1.0.28505；仅使用测试文稿副本，未改动用户原稿。

- `Shapes.AddCurve`：一维、N×2、2×N JavaScript 数组均返回“方法执行失败”。
- `BuildFreeform.AddNodes`：传入起点 `(100,100)`、控制点 `(100,200)` / `(200,200)`、终点 `(200,100)` 后，保存出的 PPTX 含多余的 `(0,0)` 连线，且原本一段三次贝塞尔被重新拟合为三段不同曲线。只检查外接矩形无法排除此错误。
- 原生 DrawingML 导入（单次复制检查）：写入 `custGeom/cubicBezTo`，在隐藏临时文稿中打开，复制原生形状到目标幻灯片。再次保存后，原始控制点、位置、72% 不透明度及无线条属性均保留。不是图片，也不是折线。此检查不覆盖已有候选区域时再次粘贴的行为，见下方操作顺序回归。
- 用此前诊断中的剪角矩形、禁止符和七边形重建的组合，输出 9 个独立色块；已在 WPS 中打开检查，曲边与叠加的源轮廓相接。此检查不等同于插件面板整个点选流程的实机验收。

## 本轮代码修正

- 圆弧：DrawingML 极角转换为椭圆参数角后再生成贝塞尔控制点。
- 单外框模式：保留原始曲线元数据，不能在切分时丢成折线。
- 近点合并：仅合并数值误差造成的重复节点；不同位置的真实交点不再应用视觉合并容差（见下面的圆柱＋棱台案例）。
- 不相连的嵌套轮廓：为外部区域建立孔洞，孔洞采用反向子路径；选择标记避开孔洞。
- 生成入口：候选色块与最终色块均走原生 DrawingML 导入，绕过上述曲线创建接口的重拟合行为。

原生导入会使用 WPS 的复制/粘贴通道，**会替换系统剪贴板内容**。临时 PPTX 在本机生成并在导入后清理，不上传。

## 圆柱＋棱台：左上色块跨越边界

按反馈截图重建 `can` 与 `bevel` 的组合，复现了 11 个区域、左上色块跨越圆柱左壁的结果。原因是 0.5～2.5 磅的空间合并将相近但不同的交点/接缝节点混为一体，改变了节点周围边的顺序，导致面追踪沿同一曲线往返并拼接不相邻区域。

修正后只按浮点数值容差去重，该重建案例形成 13 个区域。新增 `tests/can-bevel.test.js`：覆盖 4 种缩放与 5 种接缝偏移，检查左上区域截止位置、区域不重叠、边界不重复经过顶点，以及写成原生 PPTX 后的边界。真实相隔 0.35 磅的交点保留，差异 0.0000001 磅的重复交点仍合并。

这次针对截图的验证为几何与原生文件回读测试，尚未取得截图所对应原始 PPTX 做同文件实机比对。

## 先开始点选，再填充全部：整体平移

用户反馈直接填充全部正常，但先建立候选区域再填充全部时，所有色块整体向右下偏移。原生导入代码之前只检查数量，没有校准粘贴位置；重复粘贴可能产生的平移会原样保留。本次没有在真实 WPS 中复现该特定操作顺序，因此不把重复粘贴偏移机制写作已实机确认的结论。

修正：在隐藏源文稿中记录每个色块的位置、尺寸及旋转，粘贴后按唯一名称匹配，恢复 `Left/Top` 并回读检查。禁止以控制点包围盒重新缩放曲线；尺寸或旋转发生异常变化、位置还原失败时，删除本次新增色块并报错，保留原图及原候选区域。旧候选仍在新批次导入成功后才清理。

新增 `tests/native-workflow.test.js`，用真实曲线和直线路径生成原生 PPTX，配合模拟 WPS 的粘贴接口覆盖：直接全部填充、点选后全部填充、连续两次点选后填充、重复全部填充、粘贴返回顺序反转、位置不可恢复和尺寸异常。模拟接口故意在已有候选/色块时增加平移，确认成功流程坐标相同、失败流程无残留且保留旧候选。该测试不替代用户当前 WPS 的面板实机回归。未打包、未发布。

## 太阳形＋禁止符：中间色块跨越椭圆

只读检查用户指定的 `.codex-tmp/runtime-check/feedback-native.pptx`，其中是禁止符 29 和太阳形 30。使用文件的实际坐标及调整值复现：旧代码生成 21 个面，中间测试点 `(436,292)` 与左侧测试点 `(264,201)` 落入同一个面，该面的边界重复经过顶点。

原因有两处：平行但不共线的线段返回了没有有效 `t/u` 的“交点”，无效参数破坏了切分排序；曲线求交使用采样弦段边界筛选及相交条件，真实曲线交点可能不在弦段对应区间内，造成遗漏或错误的回退连接。

修正后平行不共线直接返回无交点，切分参数排序过滤非有限值。曲线候选对采用贝塞尔子段控制点包围盒保守筛选，自适应细分后在原始曲线上细化求根，并校验两侧交点残差，不再用失败的弦段交点替代真实交点。输出仍截取原始三次贝塞尔，求交细分不变成输出的碎线段。

新增 `tests/sun-no-smoking.test.js` 保存源文件两种形状的几何参数，覆盖 3 种精度和 3 种缩放，均得到 23 个不重复经过顶点的面；中间与左侧区域分开，原生 PPTX 回读后同样保持分隔与曲边。未改动用户 PPTX。这是同文件数据的几何与序列化回归，尚非当前 WPS 面板的实机验收，也不保证所有相切或重合曲线的情况均已覆盖。
