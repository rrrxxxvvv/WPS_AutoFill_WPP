# WPS 演示自动填色：普通用户使用指南

这是一款用于 **WPS 演示 Windows 桌面版** 的自动填色插件。安装和使用插件不需要 Node.js，也不需要编写代码。

## 一、安装插件

1. 在 GitHub 仓库的 **Releases** 页面下载最新版 `wps-autofill-wpp.exe`。
2. 保存并关闭正在运行的 WPS。
3. 双击安装程序。
4. 出现“确定要安装 wps-autofill-wpp？”时选择确定。
5. 安装完成后重新打开 WPS 演示。

> 安装程序目前没有代码签名。Windows 或安全软件可能提示“未知发布者”，请确认安装包来自本项目的 GitHub Release 后再运行。

## 二、打开插件

1. 打开或新建一个演示文稿。
2. 在 WPS 顶部功能区找到 **自动填色**。
3. 点击 **自动生成填色区域**。
4. 右侧出现“自动填色”任务窗格后即可使用。

如果没有看到“自动填色”选项卡，请完全退出 WPS 后重新打开。仍未出现时，请确认使用的是 WPS 演示 Windows 桌面版，而不是网页版或移动版。

## 三、选择图形类型

插件支持三种结构。操作前请先判断自己的图形属于哪一种。

### 方式 A：外框与分割线

适用于一个闭合外框，里面有若干分割直线的图形。

1. 点击一次 **闭合外框**；
2. 插件会自动读取当前页中的直线；
3. 回到右侧任务窗格设置颜色；
4. 选择手动填色或全部填色。

如果页面中还有不属于该图形的直线，可按住 `Ctrl`，精确选中外框和需要的分割线。

分割线需要完整穿过外框，建议让线段两端稍微超过外框边缘。

### 方式 B：椭圆节点线网

适用于由许多椭圆节点和连接线组成的网状图形。

1. 点击幻灯片空白处，取消所有对象的选择；
2. 插件会扫描当前页的椭圆节点和连接线；
3. 回到任务窗格设置颜色；
4. 选择手动填色或全部填色。

每条连接线的两端应连接到两个椭圆边缘，外围线网需要闭合。

### 方式 C：通用线稿

适用于多个多边形、直线和自由曲线相互重叠或相交的图形，不要求存在唯一外框。

1. 点击幻灯片空白处，取消所有对象的选择；
2. 插件会自动扫描当前页中可读取的路径；
3. 如果页面上有无关对象，可以先框选需要参与识别的全部路径；
4. 选择手动填色或全部填色。

插件会在交点处拆分路径，并把形成的每个闭合面作为独立候选区域。自由曲线控制点无法读取时，会按现有节点作折线近似。

## 四、设置填充效果

任务窗格中的常用设置：

- **填充颜色**：使用取色器、经典颜色，或之前临时保存的颜色；
- **保存当前**：保存当前颜色，之后可以直接点击复用；
- **不透明度**：数值越高，颜色越不透明；
- **曲边精度**：通常保持“标准”即可；
- **同色系调色板**：为不同区域自动生成相近颜色；
- **包含椭圆内部区域**：让每个椭圆节点内部也可以单独填色；
- **关闭原外框/节点填充**：防止原图形的白色填充遮住新生成的颜色。

## 五、填充区域

### 只填几个指定区域

1. 点击 **开始点选**；
2. 幻灯片上会出现浅色候选区域；
3. 直接逐个点击想填色的区域，不用按 `Ctrl`；
4. 已点选区域会加深，再点一次可以取消；
5. 点击 **完成并填充**。

是否选中请以区域颜色是否加深为准。没有点选的候选区域会在完成后自动清除。

WPS 对自由形状固定使用矩形外接控制框，无法显示成贴合复杂轮廓的选择框。插件会在每次点击后自动记录区域并立即取消 WPS 原生选择，因此矩形框只会短暂出现，不会一直挡住相邻区域。

### 一次填充全部区域

点击 **填充全部识别区域**。插件会为识别到的全部闭合区域生成颜色。

## 六、修改或清理

- **修改颜色**：在幻灯片中选中一个或多个已生成区域，再点击 **给选中区域换色**；
- **删除结果**：点击 **清理本页生成区域**，清除当前幻灯片中的候选和生成区域；
- **保存结果**：像普通演示文稿一样保存即可，生成的区域会作为 WPS 图形保存在文件中。

## 八、常见问题

### 点击按钮后没有反应

- 外框模式：检查是否选中了一个闭合外框，分割直线是否完整穿过外框；
- 线网模式：检查是否已点击空白处，取消全部选择；
- 通用线稿模式：检查各条路径是否真实相交或首尾连接，并确认没有很小的断口；
- 检查线段两端是否确实靠近椭圆边缘；
- 查看任务窗格底部显示的红色或黄色提示。

### 椭圆内部颜色看不见

同时启用：

1. **线网模式包含椭圆内部区域**；
2. **关闭原外框/节点填充，只保留轮廓**。

### 生成结果不正确

先点击 **清理本页生成区域**，检查线段、椭圆和外围边界是否闭合，然后重新生成。报告问题时，请提供经过脱敏的示例文稿、WPS 版本、Windows 版本和错误截图。

### 如何更新插件

关闭 WPS，下载并运行新版安装程序，然后重新打开 WPS。
